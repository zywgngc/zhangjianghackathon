# 示例图标目录

18 个真实 SVG 来自 [Game-icons 官方仓库](https://github.com/game-icons/icons)，上游版本固定为
`82d948812bfe3f269ef8f731dcdb07b08160edc4`。

作者：Guard13007、Delapouite、Lorc。素材采用 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。上游说明见 `UPSTREAM-LICENSE.txt`。

图标按原始字节保存，未修改。每个文件的来源、署名、许可和 SHA-256
记录在 `catalog.json`；交付模块自动生成最终使用素材的 `CREDITS.txt`。

这些图标覆盖暂停、播放、生命值、金币、氮气、瞄准、弹药、转向、速度、
车轮、跳跃、鱼、设置、声音、静音、奔跑、箭头和治疗药水。
此目录不包含 3D 模型、角色动画或场景资产。
