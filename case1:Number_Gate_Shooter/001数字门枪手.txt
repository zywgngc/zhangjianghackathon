==================================================

Recreate the complete core gameplay of
Soldier Assault.

The player controls a squad of armed soldiers.

The squad moves forward automatically.

The player controls horizontal movement.

Mathematical gates change the number
of soldiers in the squad.

Every soldier automatically shoots enemies.

The player must grow the squad, avoid hazards,
and defeat the final Boss.

Preserve the following systems:

1. Automatic forward movement
2. Horizontal squad movement
3. Mathematical gates
4. Soldier multiplication
5. Soldier reduction
6. Automatic shooting
7. Enemies and obstacles

9. Level progression

==================================================
04. PLAYER CONTROL SYSTEM
==================================================

04.1 Movement

The squad moves forward automatically.

The player controls horizontal movement
using a single finger.

Touch and drag left:
Move the squad left.

Touch and drag right:
Move the squad right.

Release:
Stop horizontal movement.

Forward movement continues automatically.

Desktop users may use mouse dragging.

04.2 Movement Parameters

World coordinate system:

X = horizontal road direction
Y = vertical height
Z = forward direction

Road width:
12 world units

Initial squad position:
X = 0

Movement speed:
6 world units per second

Forward movement speed:
8 world units per second

Horizontal movement:
Smooth interpolation toward input position.

Input smoothing time:
Approximately 0.10 seconds.

Input must remain frame-rate independent.

04.3 Road Boundaries

The squad center must remain inside
the valid road area.

The player's horizontal position
must be clamped to:

-5.5 <= X <= 5.5

Squad members may visually extend beyond
the center position, but must not cause
incorrect gate collisions.

04.4 Shooting

Shooting is fully automatic.

The player does not manually aim or fire.

All living soldiers participate in shooting.

04.5 Pause

The game must support pausing.

While paused:

- Forward movement stops
- Soldier movement stops
- Enemy updates stop
- Shooting stops
- Collision processing stops
- Timers stop
- Animations stop where appropriate

==================================================
06. MATHEMATICAL GATE SYSTEM
==================================================

06.1 Soldier Count

Let:

N = current number of soldiers

Initial soldier count:

N = 1

Permanent upgrades may increase
the initial soldier count.

Maximum soldier count:

N_MAX = 200

Minimum soldier count:

N_MIN = 0

If N reaches zero, the player loses.

06.2 Addition Gates

Example:

+5

N_new = N + 5

06.3 Subtraction Gates

Example:

-3

N_new = N - 3

06.4 Multiplication Gates

Example:

×2

N_new = N × 2

06.5 Division Gates

Example:

÷2

N_new = floor(N / 2)

06.6 Boundary Rules

After every operation:

N_new = max(0, min(200, N_new))

The result must always be an integer.

Division uses floor rounding.

Division by zero is prohibited.

06.7 Gate Activation

Each gate can activate only once.

Each gate group can trigger only
one selected gate.

When the squad passes a gate group,
the selected gate is determined by
the horizontal position of the squad center.

The selected gate applies to the
entire squad.

Individual soldiers must not
trigger the same gate independently.

After activation:

- Update soldier count
- Update squad formation
- Display numerical feedback
- Play an appropriate effect
- Mark the gate as consumed

06.8 Gate Presentation

Positive gates:

Green or cyan.

Negative gates:

Red.

Positive or negative classification
must be based on the actual result
for the current soldier count.

For example:

Current soldiers = 10

×2 is positive.

÷2 is negative.

06.9 Example

Initial squad:
1 soldier

Gate 1:
+5

Result:
6 soldiers

Gate 2:
×3

Result:
18 soldiers

Gate 3:
-4

Result:
14 soldiers

All 14 soldiers automatically shoot.


==================================================
07. COMBAT AND COLLISION SYSTEM
==================================================

07.1 Soldier Weapon

Weapon:
Assault Rifle

Base attack frequency:
2 attacks per second per soldier

Base bullet damage:
1

Projectile speed:
30 world units per second

Maximum projectile lifetime:
3 seconds

07.2 Damage Calculation

Let:

N = soldier count
R = attacks per second
D = damage per bullet

Theoretical total damage per second:

DPS = N × R × D

With:

N = 20
R = 2
D = 1

DPS = 40

Actual damage must respect
projectile hit detection.

07.3 Targeting

Soldiers automatically target
the nearest valid enemy ahead.

When several enemies are available:

1. Prioritize the closest enemy ahead.
2. Prefer enemies within the soldier's lane.
3. Retarget when the current enemy dies.
4. Target the Boss when no ordinary enemy
   remains in the Boss area.

07.4 Enemy Soldiers

Normal enemy health:
10 HP

Normal enemies do not shoot
in the initial release.

When an enemy collides with the squad:

- Remove one living player soldier.
- Remove the colliding enemy.
- Trigger hit feedback.
- Prevent multiple losses from the
  same collision event.

07.5 Obstacles

Sandbag barricade:
Lose 2 soldiers on collision.

Barbed-wire barrier:
Lose 3 soldiers on collision.

Mine field:
Lose 5 soldiers on collision.

Each obstacle activates only once.

Apply the soldier loss immediately.

Do not allow soldier count below zero.

07.6 Squad Elimination

If N <= 0:

- Stop forward movement
- Stop shooting
- Disable active gameplay input
- Trigger defeat animation
- Open defeat screen

07.7 Projectile Performance

Use projectile object pooling.

Avoid creating large numbers
of unnecessary independent objects.

The visual projectile system may use
batching or simplified rendering.

However, gameplay damage calculations
must remain correct.

Do not reduce actual weapon damage
to improve rendering performance.


==================================================
08. BOSS SYSTEM
==================================================

08.1 Boss Theme

The Boss is an armored military vehicle.

Use a low-poly military vehicle model.

The Boss should be significantly larger
than normal enemies.

08.2 Boss Behavior

The Boss appears in the final section
of each level.

The player's squad continues moving forward.

Soldiers automatically target the Boss.

The Boss receives projectile damage.

The Boss has a visible health bar.

08.3 Victory

If Boss HP <= 0 before the squad reaches
the end of the road:

The level is completed.

08.4 Defeat

If the squad reaches the end of the road
while Boss HP > 0:

The player loses.

If the soldier count reaches zero:

The player loses immediately.

08.5 Boss Parameters

Level 1:
150 HP

Level 2:
300 HP

Level 3:
500 HP

08.6 Boss Destruction

When Boss HP reaches zero:

- Stop combat
- Play destruction animation
- Trigger explosion particles
- Stop level progression
- Calculate rewards
- Display victory screen
