# 棋盘、消除、记忆和回合制游戏
棋盘、2048、五子棋、卡牌、记忆翻牌适合 DOM，事件委托或每格绑定一次事件。逻辑状态与 DOM 渲染分离，只有合法动作改变棋盘。合法移动后更新分数与胜负，再渲染；动画期间阻止重复输入。随机初始化必须保证可玩，胜负均有真实可触达路径。计时类拼图 running 时持续更新 ticks，暂停时停止计时和输入。

2048 每行先去零，按方向扫描相邻相同数字只合并一次，补零，每次合法移动后随机生成 2 或 4，移动无效时不生成，达到目标胜利且允许继续或重开，满盘无相邻可合并时失败。翻牌游戏两张不匹配延迟盖回，重开取消所有待执行 timeout，防止旧回调污染新游戏。

关卡数、卡牌数、目标分数、胜负判断、特殊规则来自用户明确要求；其余记录为假设，不能把未实现的规则写进说明。按钮可访问，键盘和触屏一致。需要验证开始、合法操作、暂停继续和重开。
