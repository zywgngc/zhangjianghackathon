# 动作游戏输入、碰撞和数值规则
动作、接物、躲避、射击、平台跳跃应同时支持键盘和触屏。按住左右按钮用 pointerdown/pointerup/pointercancel；按键 keydown/keyup。窗口失焦清空按键，避免持续移动。屏幕方向变化后重新计算尺寸，不能让玩家飞出边界。canvas CSS 尺寸与逻辑坐标按 boundingClientRect 换算，设备像素比上限 2。

用 requestAnimationFrame，时间差 dt=Math.min((now-last)/1000,0.05)。速度以像素每秒表示，位置 += speed*dt，禁止随帧率改变难度。矩形碰撞 AABB 或圆形距离。遍历删除物体用倒序或 filter，避免漏检。跳跃必须落地判断，避免无限连跳。敌人或掉落物按累计秒数生成，游戏初期留出反应时间，不能几秒内强制失败。

示例接星星：移动接收器，接到星星 +10，接到炸弹损失 1 条生命，星星漏接损失 1，初始 3 条生命，目标 100 分胜利，生命为 0 失败。计分、生命、目标和反馈必须同步。把用户要求的数值作为优先，缺失数值明确列入假设。
