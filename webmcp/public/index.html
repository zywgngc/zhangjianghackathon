一个模糊的创意，
也能开始做游戏。

提供图片引用、几句想法或核心特征。系统补全可修改的选项，你来选，也可以直接用默认方案。

当前使用规则提案与模拟素材门户，尚未接入图片理解和真实源码检索。 补全内容是提案，验收是待验证的草案，不代表用户已确认或游戏已生成。

使用说明：给创意 → 选方案或用默认 → 拆分机制 → 导出蓝图
  1. 给一点线索：创意、核心特征或图片引用，提供其中一项即可。无需预先写完整验收要求。
  2. 补全细节：“先给我选项”会在原型检索后暂停，展示推荐。只改在意的项，也可以不修改、直接继续；或在开始时选择“自动补全”。
  3. 看结果、提追问：选定后拆分机制，并派生验收草案。初次选择不计入追问；后续可批量调整，开发者与素材门户各有独立的 3 次追问额度。
  4. 导出、交接：蓝图 JSON 包含版本、候选来源与待验证项。“检查生成交接”只检查条件，不会启动游戏生成。刷新页面后可从历史任务继续。

当前模板覆盖跑酷、生存、解谜、平台跳跃。任意文字仍可能超出规则规划器的理解范围，原文会保留供核对。只有“测试案例”模式才导入完整测试规格。
