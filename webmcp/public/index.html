到玩法机制与实现蓝图。

选一个参考案例，按默认值开始。查看玩法拆分和候选方案，按需追问，再导出研究蓝图。

当前为演示模式：候选资料是模拟数据，尚未进行真实源码检索或游戏验收。 “部分完成”表示仍缺少验证证据，不代表游戏已生成。

使用说明：选案例 → 开始研究 → 查看或追问 → 导出蓝图
  1. 选案例：目前支持数字门枪手、武林幸存者和战力吞噬者。补充说明可以留空。
  2. 选偏好：默认优先贴合案例引擎；“可移植算法”更关注可跨引擎复用的实现思路。规格已锁定的引擎和玩法不会被更改。
  3. 看结果、提追问：右侧显示生效选择与来源，下方显示机制和候选数量。开发者与素材门户各有独立的 3 次追问额度，首轮不计入。
  4. 导出、交接：蓝图 JSON 包含版本、候选来源与待验证项。“检查生成交接”只检查条件，不会启动游戏生成。刷新页面后可从历史任务继续。

补充说明会进入检索上下文；当前版本不会把自由文本自动改写成新玩法。取消任务会停止后续研究，保留已有记录。
